Orrery

A project tracker drawn as a personal galaxy.

Open it Source All projects

Every project is a planet. Every task you finish becomes a piece of that planet. Everything still open orbits it as dust until you crystallize it, and then the dust spirals in and the planet grows.

The point is to make finished work permanent and visible. Most trackers are built around what is still outstanding, so the reward for completing something is watching it disappear off a list.

It tracks real work

That is the rule that kept it honest. A parody of a dashboard would have been quicker to build, and I would have stopped opening it inside a week.

Decided before any code

Serene and cosmic. Deep blues, nebulas, ambient sound, no neon and nothing cartoonish. Navigation is click and zoom with the camera gliding, with no ship and no free flight, because free flight turns a calm space into a chore. Finishing a project gets a bloom of light and a soft chime rather than a fireworks show.

Planets generate themselves

Appearance is deterministic from the project id, so a project always looks like itself, with hue in a teal to violet range, latitude banding, polar caps and scattered bright faces that read as cities.

What is missing

Being honest about a personal tool: there is no task editing after creation, only complete, uncomplete and delete. Overdue shows as amber text in a panel and does nothing in the scene. Planet positions shift when you delete a project, because the layout is index based rather than tied to ids. And it is still one file of about eleven hundred lines that wants breaking up.
