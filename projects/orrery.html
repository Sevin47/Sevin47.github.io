Orrery

A project tracker rendered as a personal galaxy.

Open it Source Three.js Local first

The idea

Every project is a planet. Every task you finish becomes a physical fragment of that planet. Everything still open orbits it as stardust until you crystallize it, at which point the dust spirals in and the planet visibly grows.

The point is to make finished work permanent and visible. Most trackers are built around what is still outstanding, and the reward for completing something is that it disappears from the list.

The one rule

It tracks my actual work. That kept it honest. A parody of a dashboard would have been easier to build and I would have stopped opening it within a week.

Art direction, decided before any code

Serene and cosmic. Deep blues, nebulas, ambient sound. Not neon, not synthwave, not cartoonish. Navigation is click and zoom with the camera gliding, with no ship and no free flight, because free flight turns a calm space into a chore.

Finishing a project gets a quiet celebration: a bloom of light and a gentle chime, then a soft three note chord if it was the last task. It is deliberately not a fireworks show.

Planets generate themselves

Planet appearance is deterministic from the project id, so a project always looks like itself. Hue sits in a teal to blue to violet range, with latitude banding, polar caps and scattered bright faces that read as cities of light.

The parts that change are the parts that should. Radius grows with the number of completed tasks. Rings appear at eight crystallized tasks. A brand new project with nothing done renders as a small pulsing molten core, which is the closest thing the app has to an empty state.

The interactions

  • Selecting a planet glides the camera in and splits it apart into its fragments. Each fragment is one completed task, and clicking one shows what it was.
  • Open tasks orbit as 64 particle clusters, each at its own radius, speed and inclination.
  • Crystallizing spirals the dust inward over about 1.35 seconds, then the planet rebuilds with the new fragment in place.
  • Leaving the view reassembles the planet.

Everything saves to local storage, debounced, and stays there until deleted. There is no account and no sync.

Accessibility in a scene like this

prefers-reduced-motion slows the rotation, disables the parallax drift and skips the dust spiral animation entirely. Ambient audio is off by default and only starts on a real click, which browsers require anyway. Panels dock to the bottom below 640 pixels.

An ambient 3D scene has more ways to be unpleasant than a normal page, and most of them are motion.

What is still missing

Being honest about a personal tool: there is no task editing after creation, only complete, uncomplete and delete. Overdue only shows as amber text in the detail panel and does nothing in the 3D scene. Planet positions shift when you delete a project, because layout is index based rather than id stable. And it is still one 1,100 line component that wants breaking up.

What I would tell someone building this

  • Deterministic generation from a stable id is what makes a generated thing feel like a place rather than a screensaver.
  • Make completion the thing that accumulates on screen. A list that shrinks when you succeed is a strange reward.
  • If you build a tool for yourself, put your real data in it immediately. The fake version will lie to you about what it needs.
