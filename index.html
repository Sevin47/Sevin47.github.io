I build small browser games and map tools, mostly on top of real-world data. Real roads, real land cover, real weather, real coordinates. Everything here runs in a browser with nothing to install.

Each one has a build notes page. Those are the parts I found interesting: the thing that broke, the model I threw out, the number I measured wrong the first time.
